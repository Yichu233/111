# 爱教学：面向角色的课程工作流程

## 任务与依据
教师需要从任课进入课前准备，主任需要跨教学班核查信息，督导需要把安排、材料与登记事实放在一起阅读。沿用现有八条Must接口和桌面端范围，不引入成绩、作业、审批、排课和真实校内身份认证。

参考官方文档：
- D2L My Courses：当前任课、收藏、近期访问组织入口。https://community.d2l.com/brightspace/kb/articles/4837-about-the-my-courses-widget
- Blackboard Ultra Course Navigation：课程空间、内容与详情、稳定返回路径。https://help.anthology.com/blackboard/student/en/getting-started/navigate-inside-a-course.html
- Canvas Link Validator：以具体资源及入口为单位定位可访问性问题。https://community.instructure.com/en/kb/articles/661141-unknown
教学督导与教研室核查是爱教学对现有业务的适配，不宣称这些LMS提供完全相同的角色流程。

## 编码前方案
颜色：墨蓝#182E50、主蓝#2563EB、淡蓝#EAF1FF、白#FFFFFF、画布#F3F5F9、琥珀#B77820。保留现有门户识别度。字体Microsoft YaHei UI；标题27px、章节17px、正文14px、表格13px。内容左对齐。

```
全局侧栏 | 当前身份与学期
         | 工作台：角色任务入口 + 已有概况
         | 课前准备 / 开课核查 / 督导查阅
         | 搜索 + 需要关注/收藏筛选 + 导出当前结果
教师     | 教学班准备卡 → 安排/资源/本机备忘
主任     | 开课核查表 → 信息缺口/资源问题 → 具体课程
督导     | 开课事实列表 → 安排/资料/记录 → 原始来源阅读
```

每一条提醒给出对象、依据、建议下一步和原始页面入口；不生成假待办、假期限和假完成率。加载失败单列“未读取”，不当成零；“无资料”只指当前授权返回范围；限制访问不视作资源质量缺陷。督导状态原文保留，不将无记录推断为未督导。

复核：放弃三种角色共用一组指标卡的方案，改为教师卡片、主任核查矩阵、督导开课查阅；聚合详情重用真实API数据，避免新增与业务无关的按钮。UI/UX Pro Max筛选/空结果检索命中反馈与搜索规范，采用可见字段标签、清除条件、结果数和可恢复空状态。frontend-design负责结构，Taste核查内容价值，Prism核查列表详情与数据反馈。

## 本机功能边界
收藏、查阅备忘只在当前浏览器保存，按账户、学期、开课隔离；不能代表官方审核或与团队同步。导出仅当前筛选和授权范围，注明模拟数据、学期、身份与读取时间；CSV防公式注入。原始来源仍由后端鉴权，页面切换中止旧读取。

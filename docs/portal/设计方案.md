# 爱教学 · 桌面教学门户

## 本轮设计判断
旧页面把身份选择、目录、详情、资料和例外状态同时铺开；左侧入口只是滚动或切换同一个区块，用户难以建立“我在哪个页面”的认识。此次重新建立产品级信息架构。

主要任务：教师找到任课与资料；主任统览授权开课并进入课程核查；督导按开课定位登记事实及来源。用户已了解“课程、教学班、资源、督导”的业务含义，不需要在每一屏解释技术关系。

## 页面与导航
```
全局侧栏                  顶栏：当前页面 / 学期 / 角色账户
工作台                    角色首页：学期概况 / 常用课程 / 教学安排 / 资源状态
课程中心                  搜索、卡片或列表、筛选、收藏 → 进入具体开课
教学资源                  当前学期授权资源总目录 → 按开课打开阅读页
教学安排                  按周一至周日归组的已登记教学安排
督导记录（主任/督导）      按课程、开课查登记事实与数据状态
                          课程空间：概览 / 教学资源 / 督导记录
                          阅读页面：返回课程资料 / 同课目录 / 正文 / 上下份
```
路由使用hash，支持刷新、浏览器后退与前进；一级导航与课程内导航分开。课程中心保留搜索与展示方式，阅读返回明确的课程资料页。身份切换清理前一角色数据，资源和事实仍由现有接口授权。收藏和最近访问仅保存在本机、按角色账户与学期隔离。

## 视觉系统（编码前）
颜色：墨蓝 #182E50；主蓝 #2563EB；淡蓝 #EAF1FF；阅读白 #FFFFFF；画布灰 #F3F5F9；辅助琥珀 #B77820。中文采用Microsoft YaHei UI，正文14px，页面标题28px，课程标题22px，辅助文字12px。所有内容左对齐。

首页使用深蓝学期横幅与简短任务入口；课程卡片封面用课程编号、学科线条图形区分，封面只是视觉标识。数据表用于跨课程核查，阅读页给正文足够空间。图标统一为SVG；没有装饰性动态图、假通知、伪待办或假完成率。

复核与取舍：UI/UX Pro Max通用教育搜索给出儿童字体和绿色风格，不适合本次高校工作台，未采用；二次搜索采用侧栏、面包屑、键盘焦点建议。旧版设计系统已读，用户明确要求重新设计，本文件作为本轮覆盖方案。与上版相比，此次主体是多页面导航和课程空间，不继续给双栏查询页换色。

## 官方参考
- Canvas：[Dashboard](https://community.instructure.com/en/kb/articles/664620-how-do-i-use-the-dashboard)。借鉴工作台与课程卡片、全局入口和收藏。
- D2L Brightspace：[Content experience](https://community.d2l.com/brightspace/kb/articles/6041-navigate-course-content-in-the-new-learner-experience-or-in-the-new-content-experience-lessons)。借鉴课程内容目录、正文阅读及返回内容列表。
- Blackboard Ultra：[Navigate inside a course](https://help.anthology.com/blackboard/student/en/getting-started/navigate-inside-a-course.html)。借鉴独立课程空间、页签、课程切换及稳定返回路径。
- Moodle：[Course index](https://docs.moodle.org/405/en/Course_index)。借鉴阅读页目录当前位置高亮与可收起目录。

适配既有八条Must只读能力；教学安排是开课安排的另一种展示，不创建课表或排课。汇总仅由当前授权接口结果计算；部分失败明确显示，未知不作零。数据仍为已有教学样例，统一显示“教学演示 · 模拟数据”，不冒充接入学校。技能组合：frontend-design负责结构与视觉；Taste审核信息价值；Prism审核列表/详情/接口状态；UI/UX Pro Max审核导航与可访问性。

# 爱教学 · 桌面工作空间收敛设计

目标：让教师在开课前找到材料与反馈，让主任按异常和截止日期处理事项，让督导连续完成听课准备、记录与提交。

基线：v9 实际界面和数据库。沿用现有课程档案、资料版本、听课记录与跟进闭环，不增加学生端、成绩处理或虚构校内认证。

## 视觉决定

学期工作台采用“清晰桌面＋课程索引”语言。深墨蓝 #27364B 用于稳定导航；云白 #F5F7FB 作为背景；群青 #385C9B 连接教师操作；紫灰 #705C87 区分主任上下文；赤陶灰 #8B5846 区分督导上下文；浅金 #F7EDD9 仅标示时间敏感事项。正文保持中文系统无衬线，门户标题保留宋体；数据用 Segoe UI 等宽数字。字体不依赖网络下载。

左侧导航压缩冗余学期说明并固定底部服务入口。主区左对齐，标题、筛选、结果形成连续视线；卡片只用于课程实体与角色工作区，资料使用文档列表，待办使用有状态的任务行。提高有效信息可见量，不增加无业务依据的图表。

## 已捕获问题与落实

1. 入口→教师首页：介绍区过高、侧栏滚动。压缩标题区与导航，保留今日课程。
2. 课程列表→详情→返回：增加排序、材料入口和可清除筛选，保留原筛选上下文。
3. 主任首页→核查：将缺项和待复核保持为可操作入口，颜色必须伴随文字。
4. 督导任务→记录：任务索引增加状态筛选；当前记录的四项完成度和固定保存栏可见。
5. 公开库→课程详情→返回：保存查询与分页，统一站内课程来源入口。
6. 待办→日历→跟进：按场景日期显示今天、逾期和未来事项，日历并列展示当周跟进截止日期。
7. 切换身份、断网与提交：清除旧身份状态，偏好读取失败可降级；过期会话提供恢复入口并保留未提交文本。

## 参考取舍

UI/UX Pro Max 的首轮“university teaching workspace desktop”结果偏作品集；重试“education admin dashboard”偏实时运营深色玻璃。两者均未作为本系统模板：保留其网格、筛选、对比度与状态反馈原则，采用本系统既有浅色教学工作台作为视觉基线。

参考 Brightspace 的全局导航与课程上下文，Moodle 的 Timeline / Calendar 分工，超星教师帮助中的课程资料入口，GOV.UK 的任务状态与明确动作。公开设计图库只作为密度与组件节奏参考，不复制品牌和未实现功能。

本轮按 frontend-design 先规划后自审，Taste 按实际任务删减，UI/UX Pro Max 检查导航、表单、可达性，prism-dashboard 检查数据筛选与状态，product-design audit 记录本轮截图证据。浏览器复核不等同完整无障碍认证。

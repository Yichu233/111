# 爱教学版本管理

## 历史来源

本仓库先恢复原始源码包中的 `Sprint1-history.bundle`。原始提交 `f678618`（功能与测试）和 `7ab9664`（证据及交接说明）保留原对象、作者和提交时间，没有重新生成。原分支 `codex/sprint1` 和标签 `sprint1/original` 可直接查看。

后续 `codex/import-*` 分支是现在执行的留存版本导入，用于比较真实存在的源码快照。导入提交和合并采用当前实际时间，不能当作早期逐日协作记录。自动执行者署名 Codex AI；不为成员代填贡献或人工审查结论。

## 分支规则

- `main`：整合已留存的源码版本；历史导入合并仅表示源码整合，不代表人工验收已通过。
- `codex/sprint1`：原始 Sprint 1 分支，保留恢复时位置。
- `codex/import-*`：每个留存版本一条分支，分别提交源码变化和本次复验结果，再合入main。
- `codex/sprint1-quality`：从当前代码开始的实际质量收尾。AI检查后交由成员查看diff并决定是否合入main。

## 提交、测试和审查

提交说明应指出具体变更和来源；导入记录包含文件摘要及来源目录，测试记录写实际执行结果。不得把测试脚本通过等同人工审查。实际人工审查发生后，再记录人员、日期、问题和结论。

原 Sprint 1 范围以实验一第一个切片及原型对应故事为准。当前完整平台包含后续扩展，不能把所有历史导入分支统称为一个180分钟Sprint的原始产出。

## 本地运行

各版本运行方式见对应版本 README。当前版本使用 `python -m app.server --port 18775`。运行数据库和测试输出不进入版本跟踪；已有业务数据库另行备份。

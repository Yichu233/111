# 爱教学 · 课程工作区交互设计

目标：教师快速定位本人开课与资料；教研室主任、教学督导在具体开课上下文内查阅资料和督导事实。本轮只改变桌面端前端，沿用八条 Must 的接口与角色限制。

## 设计方案（实现前）

色彩：正文墨蓝 #272443，操作靛蓝 #5146B8，辅助丁香 #ECE9FA，页面雾灰 #F5F6FA，阅读白 #FFFFFF，异常琥珀 #9A5713。中文采用 Microsoft YaHei UI，品牌字采用系统中文宋体；字号以 14px 阅读、12px 辅助、26px 课程标题分层。

```
品牌 / 角色工具 | 页面标题、身份与学期
                | 开课索引  | 课程标题 / 上下开课 / 专注模式
                | 搜索筛选  | 课程简介与开课安排（可折叠）
                | 选中开课  | 教学资源 / 督导记录
                |           | 资源筛选 → 共用/本次分组 → 侧边阅读
```

全部内容左对齐。目录留出稳定位置；阅读区取得主要宽度。把课程代码与教学班组合成开课身份，避免同一课程的不同教学班混淆。资源状态以文字和颜色共同表达。专注模式仅隐藏目录，保留返回入口与筛选状态。原始资料阅读使用真实接口，不用伪造预览。

方案自查：不采用课程卡片墙、装饰性统计图或学习进度条。现有数据只有少量开课和只读资源，卡片墙浪费空间，完成度无来源。改为紧凑开课索引、课程档案抬头、文件分组和真实文本阅读面板。靛蓝用于定位与操作，淡紫只用于课程上下文；保持亮色阅读区域。

## 官方参考与适配

- [Canvas 课程内导航](https://community.instructure.com/en/kb/articles/660740-how-do-i-use-the-course-navigation-menu-as-an-instructor)：当前功能高亮、课程内入口。适配为课程标签与角色工具的同步高亮，不复制无关功能。
- [D2L Brightspace 内容体验](https://community.d2l.com/brightspace/kb/articles/6041-navigate-course-content-in-the-new-learner-experience-or-in-the-new-content-experience-lessons)：目录与内容并排、内容分组可展开、阅读后返回目录。适配为按现有资源作用域分组、可关闭的阅读面板。
- [Blackboard Ultra 课程导航](https://help.anthology.com/blackboard/student/en/getting-started/navigate-inside-a-course.html)：课程切换、课程信息与功能导航分层。适配为筛选结果内上下开课、课程摘要和关联内容分离。
- [Moodle 课程索引](https://docs.moodle.org/503/en/Course_index)：可收起索引、选中位置高亮。适配为专注模式和当前开课定位。

这些是交互模式借鉴，不复制品牌、文案或代码，不代表与上述平台集成。模拟数据标识保留；未登记不等于零，未查到记录不等于未督导。

技能：frontend-design 制定布局与视觉；Taste 检查业务贴合度和虚构内容；Prism 检查列表、筛选、详情和错误恢复；UI/UX Pro Max 辅助检查焦点、对比和桌面可用性。其通用设计系统搜索若包含营销页建议，不应用到本工作区。

# Sprint 1接口与数据边界

应用默认仅监听127.0.0.1:8000。所有API响应禁止缓存。身份选择和所有业务数据均为模拟；业务查询只读。

## 数据对象

课程C01可以关联本学期K01、K02及上学期K05。K01由两位教师共同承担，但保持一个稳定开课标识。课程共用资源通过course_id关联，专属资料还需要offering_id匹配。督导记录按offering_id关联，记录ID独立，来源正文保存在仅服务端可读的fixtures目录。

输入样例覆盖：无任课身份、空学期、缺课程简介、无资源、缺资源来源、无入口、失效入口、受限资源、无督导记录且数据未收全。全部是人工构造的原型样例，不宣称真实学校事实。

## HTTP约定

| 方法与路径 | 输入 | 成功内容 |
|---|---|---|
| GET /api/bootstrap | 无 | 模拟身份选项、学期、当前会话身份 |
| POST /api/demo-session | JSON user_id | 身份及HttpOnly、SameSite=Strict会话cookie |
| GET /api/offerings | term_id 必填且唯一 | 授权范围内的开课items |
| GET /api/offerings/{id} | 可选course_id用于关联核对 | 课程、开课、教师及学期 |
| GET /api/offerings/{id}/resources | 无 | 关联资源与状态、可访问入口 |
| GET /api/resources/{id}/content | offering_id 必填且唯一 | 获准资料的UTF-8文本 |
| GET /api/offerings/{id}/supervision | 无 | 督导记录、数据状态、解释 |
| GET /api/records/{id}/source | offering_id 必填且唯一 | 获准记录的模拟事实来源文本 |

JSON错误结构为 `{"error":"机器可读代码","message":"用户提示"}`。400表示无效参数或课程与开课不匹配；401表示无有效模拟会话；403表示角色或资源访问被拒；404表示不存在、对象不关联或范围外。范围外开课与不存在开课返回同一种404，不泄露外系对象。

资源状态available、broken、no_entry、forbidden分别对应可访问、入口失效、暂无入口、权限不足。受限资料响应不包含正文、磁盘路径或可用正文URL；即使直接构造URL，也会重新核对会话、开课与资料授权。

## UI一致性

每次身份、学期、开课或页签查询都会取消旧请求并递增请求序号；晚到的旧响应不能覆盖当前选择。身份和学期变化立即清空旧详情，查询失败不保留上一对象作为新结果。动态内容以textContent构建，避免把数据当成HTML执行。

## 仍需团队确认

模拟角色可见范围、记录有效性的学校业务定义、真实来源接入、真实账号认证及部署方案均未作为已确认需求。当前实现用于完成Sprint 1的只读查询与异常场景演示。

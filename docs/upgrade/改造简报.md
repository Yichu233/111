# 爱教学 Sprint 1升级简报

## 目标
让教师在授权开课中快速找到教学安排和资料，让主任与督导在同一具体开课上下文中核查事实和来源；所有结果明确区分无数据、未知、不可用和无权访问。

## 对评分项的实际贡献
|评分项|本轮实施方向|仍由人类完成|
|---|---|---|
|代码与DoD 20%|业务约束、错误恢复、服务端及桌面回归、关键注释|人工diff审查与故事验收|
|交付完整规范25%|统一版本、README、测试报告、可运行源码包、追溯矩阵|最终提交确认|
|人机协同与真实性20%|保存真实变更、测试结果、技能执行记录，不伪造失败或修复|实际参与及采纳意见|
|自评与反思15%|输出可核对的缺陷、取舍、限制与测试证据|成员客观评级|
|Scrum过程20%|提供待办与增量证据|实际会议与过程记录，本轮暂不代写|

## 计划改造
1. 沿用八条核心故事，建立需求—规则—实现—测试对应关系。
2. 通过ba2db分阶段检查课程/开课、联授、资源作用域、督导事实与来源的数据关系；DBMS由需求推导。
3. 采用Prism的列表/表格—详情模式，增加适量筛选与排序、清楚的上下文、稳定的加载/失败/空结果提示；从实际API读取模拟数据。
4. 修复旧浏览器脚本与角色页签的不匹配，加入身份失败、快速切换、恢复和空值场景。
5. 在独立副本中保存旧源码及修改，完成后提供可运行包与真实证据；不自动冒充人工审批或合入决定。

## 设计方向
课程索引式桌面工作台：墨蓝导航、钴蓝交互、朱橙提示、浅灰阅读底；使用可读表格与关联详情，降低首屏大块介绍的占用。图表只表达已返回范围内的课程/开课数量，不添加评分或覆盖率。

现有版本完整保存在原目录，本副本为 outputs/lab2-upgrade-v2/project。

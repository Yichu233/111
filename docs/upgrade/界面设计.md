# 桌面工作区设计取舍

2026-10-11。任务是让教师、主任和督导在自己可见的开课内快速找到教学班，再查看关联资料与事实。沿用现有数据、角色页签、资源状态与来源，不补造业务数字。

颜色：墨蓝 #182b49 为固定身份栏；钴蓝 #235bc5 标记当前开课和操作；浅灰蓝 #eef2f7 提供阅读背景；白 #ffffff 为表格与详情；橙褐 #9b501a 专用于异常和信息缺口；正文 #23344c。

字体：Microsoft YaHei UI / Microsoft YaHei 面向本机中文界面；27px 页面标题、23px 详情标题、14px 课程名称、12px 表格与正文。左对齐，较小的辅助文字只承载编号与标签。

布局：196px 品牌和角色栏；顶部身份与学期；下方双栏授权开课表格、选中详情。课程、班级、任课教师是表格的主体。只在必要状态下显示重试。桌面最低1100px，手机端明确不在本轮。

复核：删除旧关系展示大图、结构统计条与重复引导卡片，把首屏空间留给检索和真实记录。搜索/排序/联授筛选为本次可用性改进，不等于新增故事被追认批准。实际截图另附测试证据。

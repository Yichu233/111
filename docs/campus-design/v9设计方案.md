# 爱教学 v9：完整教学工作空间

目标：从统一门户进入身份工作空间，跨课程处理任务、维护资料和跟进质量问题，操作可追溯。

范围：保留教师、教研室主任、教学督导；增加门户、任务与动态、站内公开课程库、教学团队目录、个人设置、使用帮助和资料版本维护。身份入口是本地场景会话，不伪装学校统一认证。无新增虚构通知、教务处电话或实时学校数据。

设计：墨蓝 #26364C、纸白 #F7F8FB、鸢尾 #696487、淡杏 #F4E4D2、湖蓝 #DCEAF3、淡青 #DFEDE7。品牌采用书页和学期排课的几何组合，门户以大字与非装饰性产品入口对齐；工作区按全局、业务、服务分层。正文微软雅黑，数据Segoe UI，门户标题宋体与无衬线搭配。28/18/14/12字体尺度，8px间距；按钮10px、分区16px，主体左对齐。

布局：门户左侧品牌和已实现模块，右侧身份选择；工作空间左侧分组导航，顶栏课程入口/任务/身份，正文按角色呈现。动态使用时间线，团队使用名录，资料使用阅读器和版本列表，避免统一大卡片堆叠。

预审取舍：UI/UX Pro Max两次整体查询分别返回作品集/营销推荐，不直接套用，保留其一致性、键盘、对比度原则，实际信息架构以D2L和Blackboard官方工作流为依据。frontend-design负责结构，Taste检查业务真实性和信息取舍。

新业务规则：个人设置与课程收藏按用户隔离；读取标记只影响个人动态，不关闭业务待办；资料编辑仅限本课教师，保留旧版与操作记录；草稿日志不向其他身份展示；退出撤销当前会话。所有原有用户数据复制保留，测试使用独立数据库。

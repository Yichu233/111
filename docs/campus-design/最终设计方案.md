# 爱教学：课程与教学事务工作空间

目标：教师快速完成备课与回复，主任处理资料缺项与复核，督导按日程记录课堂观察。

视觉：墨蓝 #27384F、云白 #F5F6FA、雾蓝 #E5EDF9、淡杏 #F8EADD、松石 #DDEFE9、鸢尾 #EAE5F4。正文 Microsoft YaHei UI，数据 Segoe UI，品牌保留宋体“教”字。正文14–15px，说明12–13px，标题28px。8px间距系统，按钮10px、面板16px，状态不单靠颜色。

布局：教师以横向课程册和当日课程为主，右栏待办；主任以资料矩阵和可执行指标为主；督导以待完成日程为主，右栏已提交记录。课程详情统一为上下文返回、开课选择、课程页签。避免扩大装饰横幅和无业务作用的步骤说明。

交互：保留筛选和周次链接；搜索直达资料；详情返回原入口；记录在当前浏览器页签按身份暂存，保存与提交明确区分；关闭未提交表单二次确认；无效地址给出恢复入口；读写冲突不丢表单。

取舍：仍为桌面端，原公开目录与本地场景分别保留。不添加无依据学校通知或虚构实时指标。保留既有业务数据，不重置用户操作。

参考：frontend-design、Taste、UI/UX Pro Max本地技能；D2L官方主页与课程导航说明；GitHub audit-design作为检查维度参考，未安装执行其扫描程序。UI/UX Pro Max对草稿保留未检索到精确匹配，因此草稿实现按本项目表单行为设计，采用检索命中的提交反馈、字段标签规则。

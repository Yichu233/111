# 爱教学 v9 · 学期工作台设计依据

## 任务
让教师找到下一节课并完成资料准备；让主任按开课单元识别与跟进问题；让督导完成听课记录并形成反馈。仅桌面端。

## 设计选择
海军蓝 #243B5A 为导航与重要操作；瓷灰 #F3F5F8 为背景；墨色 #243449 为正文；珊瑚 #B84E43 为待处理；青色 #246C65 为完成；赭金 #8F651E 为计划中。浅蓝、浅杏、浅青为业务分区底色，不以单一品牌色染满页面。
中文使用Microsoft YaHei UI，数字使用Segoe UI，标题30/24、节标题18、正文14/15、辅助12。主要内容左对齐，8px间距体系，表格与日历拥有不同容器层级。

教师：学期信息 / 下次课 → 课程册（左）＋待办（右）→ 周历。
主任：开课汇总 → 课程资料与督导覆盖（左）＋待跟进（右）→ 开课核查表。
督导：本周听课任务 → 日期任务列表（左）＋听课记录表（右）。

不采用搜索工具建议的作品集网格、营销Hero/CTA或纯白绿配色：这些不是日常教学工作流。主视觉通过课表、课程册页与任务色带形成，不加入无业务含义的装饰数据。

## 本项目设计提示词
为中文高校教学工作设计三种独立桌面工作台。真实公开课程目录作为参考基础，独立场景开课、教师、课表和督导任务组成可操作工作流。教师先看到课程安排与资料准备，主任先看到需要跟进的开课和统计分母，督导先看到任务及记录入口。使用海军蓝导航与多种柔和业务色；避免同尺寸卡片铺满、伪造统计、静态按钮、纯品牌色加白色。所有操作显示成功/失败与当前状态；课程明细支持直接链接；可见菜单由角色职责决定，写权限在服务器再次验证。将信息来源和场景标识放在清晰、稳定的位置。

## 数据与事实
东北大学公开课程名及目录来源保持原样。任课姓名、班级、学期安排、人数、资料正文、督导记录与跟进状态均属于独立教学场景，非东北大学实际业务。全局显示场景运行标识，详情保留公开资料与场景安排的区别。无外部系统写入。

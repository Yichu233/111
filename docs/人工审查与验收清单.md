## 审查步骤

1. 用 `git log --oneline` 查看真实提交，逐条 `git show <提交号>` 审查初次实现和后续修改。根提交可用 `git show --stat` 定位文件，不需要不存在的基线提交。
2. 按README启动；确认全部数据为模拟，检查正常路径和权限、缺失、空态。
3. 执行服务端测试，记录实际结果；核对测试是否覆盖故事的验收目标，而非只检查页面存在。
4. 检查关键模块注释、课程与开课关联、访问入口授权、错误提示和已知限制。
5. 填写每条故事的结论及问题，达到共同DoD和自身验收条件后再计入增量。

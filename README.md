# 爱教学 · 东北大学公开资料版 v6

## 运行

需要 Python 3.11 或以上，无后端第三方依赖。

```powershell
python -m app.server --port 18768
```

浏览器访问 http://127.0.0.1:18768/ 。也可双击“启动项目.cmd”。如果18768端口正在使用，可通过 --port 改用其他端口。

## 三种工作视图

教师：按学院发现课程、收藏课程、查阅历史线上课程资料、记录本机备忘。

教研室主任：查看学院及类型分布，点击分布进入台账，按批次、学院和类型筛选，导出包含来源的CSV。

教学督导：左侧检索课程，右侧连续查阅公开档案、来源材料和个人备忘。

共同功能包括快捷搜索（Ctrl+K）、分页目录、来源跳转、收藏和备忘。收藏、备忘按工作视图分别保存在当前浏览器；保存成功会显示确认。输入备忘后须点击保存，离开页面不会自动保存。

## 数据边界

本版接入的是公开课程建设资料，不是学校教务系统实时数据库。认定记录不是当前学期开课；负责人不是已确认的当前任课教师。课程代码、学分、课表、教学班、学生及督导记录没有公开来源，保持未接入或未知，不填零、不补造。工作视图切换不是校内身份认证。没有对课程质量评分，也没有进行真实学校系统联调。

新默认首页及 /api/public-catalog 使用公开资料。原版SQLite业务模型、模拟数据种子及受保护API保留用于原有回归，不在新的默认页面展示，也不与公开课程档案拼接。旧浏览器用例针对旧页面，不适用于本版默认首页。

## 验证

2026-10-15运行通过：原有35项后端回归、3项公开数据逐行与来源哈希检查、10组新页面浏览器检查。检查范围包括数据口径、筛选与导出、收藏与备忘、角色分区、来源链接、键盘搜索，以及1100/1280/1440/1920像素桌面宽度。新页面无JavaScript异常。检查结果与截图位于 artifacts/public-data；这不是实际学校用户验收。

```powershell
python -m unittest discover -s tests -v
# 如已安装Playwright及Edge，可执行默认18768端口的页面检查：
node tests/browser_public.cjs
```

界面沿用frontend-design与Taste原则：以公开课程档案为信息主体，保留紫灰色设计系统；教师按课程组织、主任按分布组织、督导按查阅对象组织。正式教学业务仍需实际学校授权数据和账户体系才能投入使用。

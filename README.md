# 爱教学 · 教学协作平台 v10

本版包含统一门户、三种角色工作台、任务与动态、站内公开课程库、教学团队、个人设置和使用帮助。公开课程档案与独立教学场景分别管理。实现的是本地可操作业务流程，不是已接入学校的生产教务系统。

## 启动

需要Python 3.11或以上。双击“启动项目.cmd”，或在项目目录运行：

```powershell
python -m app.server --port 18775
```

访问 http://127.0.0.1:18775/ 。启动后保持命令窗口运行。若端口占用，请确认是否已有本项目服务，或用 --port 指定其他端口。

## 三种角色怎样使用

- 教师：陈知远为默认场景身份，周宁等用于验证不同任课范围。首页查看任课和待办，进入课程查阅大纲、登记课前材料、确认备课。已提交听课记录在“督导与反馈”可见。主任发起跟进后，可填写处理情况并提交回复。
- 主任：陆明。查看12个开课单元的资料就绪与督导覆盖，进入教学核查或课程详情发起跟进、安排听课。听课日期必须匹配常规课表，不能重复安排或造成督导时间冲突。收到教师回复后，填写复核结论并关闭事项。
- 督导：许文清。首页查看听课日程，进入任务查阅课程材料，填写教学组织、内容呈现、课堂互动和改进建议。可保存草稿；每项达到最低完整性要求且听课日期不晚于场景日期时，才能提交。提交后教师和主任可见，记录不可重复修改。

视图切换不等于真实账户认证；目前用于本机演示，所有写入都在本地服务完成，不向学校系统发送请求。

## 数据口径

1. 公开事实：保留东北大学教务处345条认定记录和18条2018年在线开放课程资料，原始来源、行号和快照哈希均保留。课程名称可回溯至公开目录。
2. 独立场景：12个开课单元、11个课程名称、5名任课教师及主任和督导、班级人数、课表、22份初始课程文本资料、6项初始听课任务和2项初始跟进。姓名、任课与课堂内容均为场景编写，不代表东北大学实际人员业务。全局与课程详情持续标注。
3. 课程与开课分别管理。软件项目管理有两个开课单元；联合授课的一个开课不重复计数。人数按学生人次显示，不推算独立学生数。
4. 督导覆盖分子是本场景学期存在已提交记录的开课单元去重数，分母是12个开课单元。初始2/12，约17%。没有可见已提交记录不直接等于未督导。
5. 场景日期固定2026-10-15，场景学期从2026-09-07开始，此时第6教学周。课表为常规周安排，不代表学校真实校历与节假日调课。操作审计使用实际北京时间。

## 已实现的交互

课程检索与状态筛选、CSV导出、周历前后切换、课程直达链接、资料阅读与文本发布、备课核对、主任安排听课、督导草稿与提交、教师回复、主任复核关闭、快捷搜索、状态反馈及失败提示。所有课程写权限和流程顺序在后端再次校验。多窗口旧版本提交会返回冲突，表单保留输入，可刷新业务状态后核对重试。

资料当前以文本正文登记与阅读，不提供任意文件上传、成绩管理、学生签到、消息推送、真实SSO或学校数据库连接。资料支持本课教师在线编辑并保留历史版本；暂不提供撤回或文件附件上传。已提交督导记录不可修改。听课编辑内容会按身份和任务暂存在当前浏览器页签，切页或刷新可恢复；明确显示尚未保存到服务器。保存草稿后才进入持久化数据库，正式提交后才对其他角色可见。其他业务弹窗如有未提交输入，关闭前会确认是否放弃。关闭浏览器页签可能清除暂存，换设备不可读取本页暂存。

## 设计与验证

使用frontend-design、Taste、UI/UX Pro Max；检索到的作品集/营销页面建议不适用于本系统，未直接套用。以学期事务、课程册页、听课日程作为布局主体，用海军蓝导航和浅蓝、杏色、青灰、淡紫区分任务区域。桌面宽度1100—1920px，无手机端适配承诺。

参考来源与本项目设计提示词见 `docs/campus-design/设计规范与参考.md`。

`tests/check_design.py` 另外复核早期只读模型的32项数据需求、8张表、37列和29条正反约束断言，均通过；此结果仅适用于 `app/schema.sql` 与 `workspace/aijiaoxue`，不代表当前工作空间的JSON状态表被该数据字典覆盖。本轮恢复了源码包中缺失的原版设计附件，并校验DDL完全一致。当前工作空间由 `test_campus.py`、`test_workspace.py` 等业务测试覆盖。测试不等同于真实学校验收、完整无障碍认证或生产安全审计。

## 页面上下文

课程详情的返回入口会保留原来的任务、周历和筛选条件；开课选择器在同一页签切换教学班。主任汇总数字可直接进入对应筛选结果，待办进入具体跟进事项。资料搜索直接阅读命中的正文。无效地址显示明确恢复入口。未来听课任务可准备草稿，但提交按钮不可用。

## 完整工作空间

1. 门户：首次访问选择场景身份与账号，再进入工作空间；已有会话可继续工作。无学校密码收集，不伪装统一身份认证。
2. 任务与动态：待处理事项依据当前业务状态生成，点击进入具体课程、记录或跟进。业务动态来自实际操作日志；标记已读仅改变个人阅读状态，不会完成业务任务。督导草稿操作仅本人可见。
3. 站内公开课程库：345条认定记录，支持关键词、单位筛选、分页与详情来源追溯。门户允许访客直接浏览同一套课程库页面；旧版公开目录仍保留在/public作为兼容入口。
4. 教学团队：按当前可见课程列出任课关系；不提供未经来源证实的电话号码或邮箱。
5. 个人设置：保存显示密度、默认进入页、常用课程；设置按场景账号分别保存在服务端SQLite中。退出会撤销当前服务器会话；若有未保存的听课输入，会先提示处理。
6. 课程资料：任课教师可编辑本课资料，每次保存形成新版本并保留原内容；主任与督导可读可追溯，不能代替教师编辑。
7. 帮助中心：可搜索课程准备、草稿、反馈、资料等操作说明，并直接进入相关页面。

## v10 桌面交互收敛

- 教师、主任、督导以群青、紫灰、陶褐识别工作上下文；固定导航与独立滚动区域保证常用服务入口在较矮桌面可达。统一表单、焦点、状态标签和密度。
- 课程可按课表、名称与待处理状态排序；资料支持关键词、课程、类型组合筛选与更新时间排序。详情返回保留查询条件。
- 待办按逾期、今天、后续与常规分类，教学周历同时显示当周跟进截止事项。课程来源在站内课程库查看，返回原课程上下文。
- 听课任务提供状态筛选、四项文本完整度和固定保存栏；完整度仅表明最低字数要求，不代替教学质量审核。任务切换保留筛选，原有草稿保护不变。
- 身份切换失败时清理旧身份页面；会话失效提供恢复入口；保存中限制重复操作。偏好读取失败可恢复默认显示。

源码包保留交付时的两份SQLite数据库快照。首次查看前可自行另存备份；删除数据库会失去已有操作记录，不建议为演示而清空。公开课程资料是公开事实，任课、课表、人数与业务记录是独立教学场景。

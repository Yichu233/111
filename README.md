# 爱教学 · 桌面教学工作空间

第15组“爱教学”实验二 Sprint 1 项目。本版重建桌面页面框架与交互，连接原有八条 Must 的只读接口。所有课程、人员、资料、安排及督导记录仍为本地模拟样例，没有接入学校系统。

## 启动

需要 Python 3.10以上、内置SQLite 3.37以上。在解压后的项目根目录执行：

```powershell
python -m app.server --port 18767
```

浏览器打开 http://127.0.0.1:18767 。也可双击“启动项目.cmd”，其默认地址为 http://127.0.0.1:8000 。保持终端运行，Ctrl+C停止。应用没有npm或pip依赖，首次启动创建var/aijiaoxue.sqlite3，后续启动保留数据库。

## 页面与操作

1. **角色入口**：显式选择教师、主任或督导，顶部账户菜单可切换五个模拟账户；这不是生产登录。
2. **工作台**：当前学期的课程、开课、资源概况，课程入口、教学安排、资料状态以及本机最近访问。主任和督导能查看已登记事实入口。
3. **课程中心**：按课程、编号、教师、教学班搜索；全部/收藏/单人/联合筛选；卡片与列表切换；按课程名称或开课编号排序。
4. **课程空间**：一项对应一个教学班的具体开课，含课程概览、教学资源，以及主任/督导可见的督导记录。上方选择器可切换开课。
5. **教学资源**：跨课程检索、所属课程和访问状态筛选；共用资源按编号去重，保留关联教学班入口。
6. **教学安排**：按周一至周日展示已有开课安排，不推断实际日期、节假日或完成状态。
7. **督导记录**：按开课展示事实、日期、来源及数据状态；“未查询到”与“资料未收全”分别保留，不推断覆盖率或评分。
8. **资料阅读**：独立阅读页，本课目录、当前位置、上下份、收起目录、明确返回课程资料、新窗口查看原文件。无权限资料不取正文。

收藏和最近访问仅保存在本机浏览器，按账户与学期隔离。路由使用hash，支持页面刷新及浏览器后退/前进。课程中心的搜索与展示方式在同次访问中返回时保留。

## 验证

```powershell
python -m unittest discover -s tests -v
```

浏览器验证另需 Node.js、Playwright与Microsoft Edge；先启动服务，然后执行：

```powershell
$env:BASE_URL='http://127.0.0.1:18767'
node tests/browser_portal.cjs
```

2026-10-12执行：35项Python测试通过，19组浏览器检查通过，无JavaScript页面异常。浏览器为本机Edge 155.0.4283.45。桌面宽度检查覆盖1100、1280、1440、1920像素。原browser_smoke.cjs、browser_lms.cjs入口转向当前门户测试，旧测试脚本留在工作目录的原版备份中。测试报告与截图位于artifacts/portal。

## 实现与范围

前端是原生HTML/CSS/JavaScript；后端为Python标准库HTTP服务与SQLite。app/static保存前端，app/domain.py执行角色和关联对象检查，app/storage.py管理只读查询，app/schema.sql保留数据库约束。本轮未改变后端接口、权限、样例内容或数据库结构。

本版没有新增作业、成绩、上传、编辑、真实身份认证或手机界面。只有已接入的页面才出现在导航中。数据加载失败明确提示；部分关联资料失败时汇总标明只含成功读取部分，不把失败当零。框架已实现不代表全功能LMS或生产环境验收完成。

设计参考与适配见docs/portal/设计方案.md。自动化结果不替代团队人工审查；本轮未新建Git提交、推送或合入主干。

# 爱教学 · 角色工作流程版 v4

面向教师、教研室主任、教学督导的桌面课程工作空间。本版在原有八条Must只读业务上增加角色任务入口、聚合查阅、筛选和清单导出。数据来自本地SQLite及已有受控接口；当前身份和业务资料均为模拟，没有接入学校系统。

## 启动
需要Python 3.10以上，内置SQLite 3.37以上；没有npm或pip运行依赖。

```powershell
python -m app.server --port 18767
```

打开 http://127.0.0.1:18767 。保持服务运行，Ctrl+C停止；也可双击“启动项目.cmd”，该入口默认使用8000端口。首次启动建立var/aijiaoxue.sqlite3，后续保留已有数据库。

## 三种角色的工作方式

| 身份 | 入口 | 工作流程 |
| --- | --- | --- |
| 教师 | 课前准备 | 在本人任课内搜索教学班 → 查看时间、地点、联合授课教师 → 打开关联资料 → 记录本机查阅备忘 |
| 教研室主任 | 开课核查 | 按教学班核对课程、安排、资源与登记状态 → 筛出需核对项 → 查看对象和依据 → 导出当前清单 |
| 教学督导 | 督导查阅 | 定位具体开课 → 同页查看安排、材料和历史事实 → 进入来源阅读页 → 返回原开课 |

公共课程中心、课程空间、资源库、周内教学安排和阅读目录保持可用。顶部可切换学期和五个模拟账户。教师不能读取督导事实或其他教师独立承担的开课；联授课程保留双方关系。

## 本版功能

- 工作台首先显示当前身份的任务入口，课程工作清单支持搜索、需核对信息、收藏筛选；取消收藏后即时更新结果。
- 主任使用跨开课核查表；教师和督导使用教学班卡片。收藏优先排列。
- 聚合查阅页把安排、资料、问题提示及相应督导记录放在一起，支持切换教学班。
- 提示逐项给出具体对象、依据及对应页面入口。区分资料入口失效、暂无入口、访问受限、说明缺项和读取失败；不自动判定教学质量。
- 督导记录按课程、班级、督导、摘要、来源、编号和起止日期筛选。筛选逐条记录生效，日期倒置有提示。
- 督导来源采用站内阅读，支持返回开课、失败重试；切页后旧响应不能覆盖新页面。后端仍检查身份、开课范围与记录关联。
- 导出的是当前筛选结果。CSV含模拟标记、学期、当前身份和读取时间，保护公式型文本，正确转义引号、逗号与换行。不会导出正文或超出授权范围的对象。
- 查阅备忘点击“保存到本机”后保存在当前浏览器；按账户、学期、开课隔离，刷新可恢复。未保存内容切页会丢失。备忘不代表正式审核，也不会同步给其他成员。
- 加载失败显示“未读取”，不当作零；已返回空列表只表示当前可见登记为空。“无记录”与“资料未收全”均保留原始登记状态，不推断未督导或覆盖率。

## 验证

```powershell
python -m unittest discover -s tests -v
node tests/browser_portal.cjs
node tests/browser_workflows.cjs
```

浏览器测试另需Node.js、Playwright和Microsoft Edge，且先启动本地18767服务。可用BASE_URL指定其他地址，ARTIFACT_DIR指定输出目录。

2026-10-15（北京时间）验证：35项Python测试、19组门户回归及13组角色流程检查通过。Edge155；页面无JavaScript异常。桌面宽度覆盖1100、1280、1440、1920，新增页面无整页横向溢出。验证包括权限、日期筛选、备忘隔离、导出内容与公式转义、未知状态、失败恢复、迟到响应以及收藏即时更新。结果与截图在artifacts/workflows。

## 目录

- app/static：前端页面与交互。
- app/domain.py、server.py：受控读取及HTTP接口。
- app/schema.sql、storage.py：SQLite结构与读取。
- tests：后端测试、门户及角色工作流程测试。
- docs/workflows：设计依据、参考来源。
- artifacts/workflows：本版测试记录和截图。

## 使用范围

本版是桌面只读查询与查阅工作空间，不是完整LMS。模拟身份切换不是生产登录；真实部署仍需要校方确认权限规则、接入可信身份认证和真实资料来源，并按实际数据量验证性能。当前没有新增作业成绩、上传审批、排课或手机端，也未将本机备忘写入学校业务记录。本轮没有更改数据库或虚构已完成的人工作业、审批、评审。

# 爱教学 · 查课程工作台设计系统

**方向：** 课程索引图谱（桌面端）  
**视觉特征：** 墨蓝首屏、钴蓝课程数据、朱橙联合授课、暖黄强调、暖纸正文。使用清楚的几何色块与边线表达对象关系，避免通用白绿后台、渐变玻璃与过多阴影。

## 目标与结构

教师、教研室主任和教学督导确认模拟身份和学期后，定位一条具体开课，再查看其课程信息、教学资源或已登记督导事实。

品牌导航 → 课程／开课关系图 → 角色任务与查询范围 → 数据构成摘要 → 左侧开课目录／右侧详情和关联页签。

## 色彩令牌

| 令牌 | 色值 | 用法 |
|---|---|---|
| 画布 `--canvas` | `#EEE9E1` | 桌面背景 |
| 正文面 `--paper` | `#FCFAF5` | 阅读与详情面板 |
| 正文 `--ink` | `#17233C` | 标题与主要数据 |
| 次级文字 `--muted` | `#4B5364` | 说明、来源、标签 |
| 品牌墨蓝 `--brand-deep` | `#172746` | 顶栏、首屏、课程关系图底 |
| 课程钴蓝 `--brand` | `#2454C5` | 课程数据与独立开课 |
| 联合授课朱橙 `--type-joint` | `#C3422E` | 联合授课类别块 |
| 暖黄强调 | `#F0C44D` | 首屏边线、关系节点和重要强调 |
| 教师角色 | `#2454C5` | 教师范围与入口 |
| 主任角色 | `#7044B8` | 主任范围与入口 |
| 督导角色 | `#BB482D` | 督导范围与入口 |
| 成功状态 | `#236245` | 仅限可用状态文字与标记 |

角色标签、状态和开课类别都保留文字，颜色不是唯一信息来源。正文面板采用浅色底，关键数字色块采用白字；状态语义单独使用明确文字。

## 字体、栅格与组件

- 中文使用 Microsoft YaHei UI、Microsoft YaHei、PingFang SC、Noto Sans SC 与系统字体回退。
- 页名约48px，工作区标题18–23px，指标数字32px；说明12–14px，元信息11–12px。
- 最大桌面宽度1540px；双栏目录—详情布局。手机端不在本轮范围。
- 课程档案 → 本次开课 → 资源／督导事实关系图作为产品识别核心。图中使用墨蓝底、纸色课程节点、暖黄开课节点、朱橙与暖黄结果块。
- 开课摘要使用暖黄范围带、钴蓝／朱橙类别块和分段构成条。课程按 `course_id` 去重；独立／联合开课计数由当前查询的开课数据派生。
- 开课目录选中态使用当前角色边线、底色和文字；联合授课只呈现一个开课记录。
- 角色快捷按钮44px高、约10px圆角；线性SVG统一18px绘图尺寸与1.75px描边，落在角色色圆形底片内。开课卡片与筛选控件使用适度圆角，状态标签用胶囊形；仅操作控件提供悬停和按下反馈，键盘焦点外框保留。
- 资源状态、督导记录来源和未知状态使用直接文字；“未查询到记录”不等于“未督导”。

## 边界

界面为本地演示；身份、授权、课程、开课、资源和督导记录均为模拟数据。不声称真实认证、接入学校系统或完成实际教学审核。未知数据不填零，不新增覆盖率、评分或其他业务指标。
